# Match me Lucky — Lucky Suki

เว็บแคมเปญจับคู่ของร้าน Lucky Suki · 2 โหมด: **Lucky Duo** (หาคู่เดต) และ **Lucky Gang** (หาเพื่อนใหม่ 4 คน)

## โครงสร้างไฟล์

```
index.html            เปิดไฟล์นี้เพื่อดู/แก้งาน (ดับเบิลคลิกได้เลย ไม่ต้องรัน server)
css/styles.css        ธีมทั้งหมด — สีอยู่ในบล็อก token ด้านบนสุด
js/store.js           อ่าน/เขียน localStorage แบบกัน error
js/i18n.js            คำแปล TH/EN ทั้งหมด + ฟังก์ชัน T()
js/data.js            โปรไฟล์ ห้อง บทแชท แท็ก น้ำซุป
js/app.js             state machine, ปัดการ์ด, ห้องแชท, ระบบโหวต, canvas น้ำซุป
build.mjs             รวมทุกไฟล์เป็นไฟล์เดียวสำหรับ publish
dist/                 ผลลัพธ์จาก build (ไฟล์เดียวจบในตัว)
```

## แก้สี

สีทั้งหมดเป็น CSS custom property อยู่ต้น `css/styles.css` **สามบล็อก** ต้องแก้ให้ครบทั้งสาม
เพราะแต่ละบล็อกคุมคนละสถานะ:

| บล็อก | ใช้ตอนไหน |
|---|---|
| `:root`                                   | โหมดสว่าง (ค่าเริ่มต้น) |
| `@media (prefers-color-scheme:dark)`      | ผู้ใช้ตั้งเครื่องเป็นโหมดมืด |
| `:root[data-theme="dark"]`                | ผู้ใช้กดสลับเป็นมืดเอง |

สีหลักคือ `--chili` (`#BD5579`) ส่วน `--chili-strong` เป็นเฉดเข้มกว่า ใช้เฉพาะตัวหนังสือ
ตัวเล็กมากๆ ที่ต้องอ่านออกบนพื้นพาสเทล

## Build

```sh
node build.mjs        # → dist/match-me-lucky.html
```

ต้องรันก่อน publish ทุกครั้ง เพราะหน้า Artifact เสิร์ฟไฟล์เดียวและบล็อกไฟล์ภายนอก
ทำให้ `css/` กับ `js/` ต้องถูกรวมเข้าไปในไฟล์ ผลลัพธ์เป็น *fragment* (ไม่มี `<!doctype>`,
`<html>`, `<body>`) โดยตั้งใจ เพราะตัว Artifact ใส่ให้เองอยู่แล้ว

## กติกาแมช

**Lucky Duo** — ปัดถูกใจตรงกัน → แชท → ทั้งคู่กดยืนยัน = แมช

**Lucky Gang** — ห้องละ 4 คน อยู่ครบเวลา 24 วิ = ได้สิทธิ์โหวต / กดออก = สุ่มห้องใหม่

| เสียงโหวต | ผล |
|---|---|
| 3–4 | แมช ✅ → First Visit + voucher ลด ฿50 |
| 2   | ไม่สำเร็จ → เข้าห้องใหม่ทันที (ดวง +3%) |
| 1   | No match ❎ → Lucky Dessert ลด 10% |

ทุกครั้งที่สุ่มห้องใหม่ โอกาสแมชเพิ่ม 3% (เพดาน 18%)
